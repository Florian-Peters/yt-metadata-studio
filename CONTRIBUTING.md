# Contributing

Thanks for considering a contribution to yt-metadata-studio.

## Good First Contributions

- Improve preset wording
- Add useful template variations
- Improve accessibility or responsive behavior
- Clarify README or documentation
- Fix small bugs without adding backend complexity

## Local Setup

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run lint
npm run typecheck
npm run build
```

## Project Direction

Keep the app local-first and beginner-friendly. Do not add authentication, a database, paid API requirements or server-side storage unless the feature is fully optional.
