# Changelog

## 0.2.1

This release improves the built-in preset system and makes the app more useful for the general public.

### Changed

- Replaced personal channel presets with generic public creator presets
- Added built-in presets for Cinematic Music Artist, Anime / Fanmade Music, Kids Learning Channel, Gaming Creator, Tutorial / Education, Podcast / Interview, Fitness Creator, Business / Product, Shorts / TikTok Viral and Generic Creator
- Improved preset wording so the app feels less personal and more useful for all creators
- Updated README to better position the project as a public open-source creator tool

### Notes

The app remains local-first and runs fully in the browser.

## 0.2.0-rc

- Added browser-based TXT and Markdown export
- Added custom presets saved in localStorage
- Added a local Metadata Score card with improvement tips
- Improved generator wording, hashtags and preset-specific output
- Added GitHub Actions CI
- Added open-source project templates and documentation

## 0.1.0

- Initial Next.js MVP
- Built-in creator presets
- YouTube titles, descriptions, hashtags, thumbnail text and TikTok captions
- Copy buttons and GitHub-ready README
